# Mon Cahier de Français (FR / EN)

Site d'exercices bilingues français / anglais conçu pour aider un élève anglophone au collège (du niveau CP jusqu'au collège).

- **10 chapitres** illustrés (bases CP, 38 verbes / 228 conjugaisons, 78 noms & pluriels, grammaire & nature des mots, menus déroulants riches, dialogues de classe)
- **Score de fin** avec bilan détaillé et mode « Rejouer mes erreurs »
- **Page QR Code** imprimable (`qr.html`) pour partager le site facilement
